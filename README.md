#Employee Payroll Management System (Core Java)

## Project Description
This is a console-based Java application developed using Core Java and Java 8 features. The system helps manage employee payroll details including salary calculation, experience-based grouping, department-wise expense analysis, and sorting operations.

## Technologies Used
Java (Core Java)
Java 8 (Streams, Functional Interfaces)
Collections Framework

## Features
Add single and multiple employees
Salary calculation with bonus & experience increment
Group employees by experience (Junior/Mid-Level / Senior)
Sort employees by skill count and salary
Department-wise salary expense calculation
Custom exception handling
Menu driven console application

## Java Concepts Used
OOP (Encapsulation, Abstraction)
Collections (List, Map)
Java 8 Functional Interfaces:
Predicate
Function
BiFunction
Consumer
Comparator
Custom Exceptions

## How to Run
1. Clone the repository
2. Compile all java files
3. Run User Interface.java
